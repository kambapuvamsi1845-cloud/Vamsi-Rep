# 7. User Flow

1. **Consumer** expresses future demand or pre-orders in the marketplace.
2. **AI Engine** aggregates historical data, market trends, and live consumer demand.
3. **Farmer** queries the Production Planner AI, which recommends planting specific crops and quantities based on the demand forecast, soil, and water availability.
4. **Farmer** logs the planted crop and field details.
5. **Smart Irrigation AI** continuously monitors mock sensor data and weather forecasts, alerting the farmer to irrigate, delay (if rain expected), or skip.
6. **Harvest AI** analyzes planting dates and weather to alert the farmer when the crop is nearing maturity.
7. **Farmer** harvests and logs the actual yield.
8. **Freshness AI** calculates an initial freshness score and remaining shelf-life, automatically pushing the listing to the Marketplace.
9. **Surplus AI** monitors sales pace against degrading freshness; if surplus risk is detected, it advises the farmer to apply automated discounts or flags bulk buyers.
10. **Consumer** buys the fresh produce. The cycle completes and data feeds back into the forecasting engine.

# 10. Database Schema (Production SQL for PostgreSQL)

```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    role VARCHAR(20) NOT NULL CHECK (role IN ('FARMER', 'CONSUMER', 'ADMIN')),
    full_name VARCHAR(255) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE farms (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    farmer_id UUID REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(255) NOT NULL,
    location_lat DECIMAL(10, 8),
    location_lng DECIMAL(11, 8),
    total_area_acres DECIMAL(10, 2),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE fields (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    farm_id UUID REFERENCES farms(id) ON DELETE CASCADE,
    name VARCHAR(255) NOT NULL,
    size_acres DECIMAL(10, 2) NOT NULL,
    soil_type VARCHAR(100),
    irrigation_method VARCHAR(100),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE crop_cycles (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    field_id UUID REFERENCES fields(id) ON DELETE CASCADE,
    crop_name VARCHAR(100) NOT NULL,
    planted_date DATE NOT NULL,
    expected_harvest_date DATE,
    actual_harvest_date DATE,
    growth_stage VARCHAR(50) DEFAULT 'SEEDLING',
    status VARCHAR(50) DEFAULT 'GROWING' CHECK (status IN ('PLANNED', 'GROWING', 'HARVESTED', 'FAILED')),
    water_used_liters DECIMAL(12, 2) DEFAULT 0,
    estimated_optimal_water_liters DECIMAL(12, 2) DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE sensor_readings (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    field_id UUID REFERENCES fields(id) ON DELETE CASCADE,
    soil_moisture DECIMAL(5, 2),
    temperature DECIMAL(5, 2),
    humidity DECIMAL(5, 2),
    rain_probability DECIMAL(5, 2),
    reading_time TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE products (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    crop_cycle_id UUID REFERENCES crop_cycles(id) ON DELETE CASCADE,
    farmer_id UUID REFERENCES users(id),
    name VARCHAR(255) NOT NULL,
    quantity_kg DECIMAL(10, 2) NOT NULL,
    price_per_kg DECIMAL(10, 2) NOT NULL,
    harvest_date DATE NOT NULL,
    freshness_score INTEGER CHECK (freshness_score >= 0 AND freshness_score <= 100),
    estimated_days_remaining INTEGER,
    status VARCHAR(50) DEFAULT 'AVAILABLE' CHECK (status IN ('AVAILABLE', 'SOLD_OUT', 'SPOILED', 'DISCOUNTED')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE orders (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    consumer_id UUID REFERENCES users(id),
    total_amount DECIMAL(10, 2) NOT NULL,
    status VARCHAR(50) DEFAULT 'PENDING' CHECK (status IN ('PENDING', 'PAID', 'DELIVERED', 'CANCELLED')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE order_items (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    order_id UUID REFERENCES orders(id) ON DELETE CASCADE,
    product_id UUID REFERENCES products(id),
    quantity_kg DECIMAL(10, 2) NOT NULL,
    price_at_time DECIMAL(10, 2) NOT NULL
);

CREATE TABLE surplus_alerts (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    product_id UUID REFERENCES products(id) ON DELETE CASCADE,
    alert_message TEXT NOT NULL,
    recommended_discount_percent INTEGER,
    status VARCHAR(50) DEFAULT 'ACTIVE' CHECK (status IN ('ACTIVE', 'RESOLVED', 'IGNORED')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

```

# 11. Row Level Security (RLS) / Data Isolation Rules

Implement data isolation at the Express API routing level via middleware.

* **Farmers:** Route `GET /api/farms` MUST filter by `req.user.id`. Farmers cannot query or modify farms, fields, crop cycles, or sensor readings belonging to others. Products created must enforce `farmer_id === req.user.id`.
* **Consumers:** Can view all active `products` (status IN ('AVAILABLE', 'DISCOUNTED')). Can only view their own `orders` and `order_items`.
* **Admins:** Have unrestricted `SELECT` access to all tables for dashboard aggregations, but modifications require explicit admin endpoints.

# 13. Gemini SDK Setup & Server-Side Security

Use the official `@google/genai` SDK. Never expose the API key to the React frontend. All AI calls must be routed through the Express backend.

```javascript
// backend/services/ai.service.js
import { GoogleGenAI, Type } from '@google/genai';

if (!process.env.GEMINI_API_KEY) {
  throw new Error("GEMINI_API_KEY is missing in environment variables.");
}

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

// Generic instantiation to be used by specific agent handlers
export const generateStructuredResponse = async (prompt, schema) => {
    const response = await ai.models.generateContent({
        model: 'gemini-2.5-flash',
        contents: prompt,
        config: {
            responseMimeType: 'application/json',
            responseSchema: schema,
            temperature: 0.2, // Low temperature for deterministic, analytical output
        }
    });
    return JSON.parse(response.text());
};

```
